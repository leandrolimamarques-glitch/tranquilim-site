# Tranquilim

Página do Tranquilim em https://tranquilim.com.br: orientação em saúde infantil escrita e revisada por médicos, da gestação aos 6 anos.

Site estático publicado pelo GitHub Pages a partir da branch `main` (pasta raiz). O domínio está no arquivo `CNAME`.

- `index.html`: a página
- `favicon.svg`: ícone da aba
- `robots.txt`: libera indexação

A página não coleta dados, não usa cookies nem formulários.
